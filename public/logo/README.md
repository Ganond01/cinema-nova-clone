# Папка для логотипу сайту (CINEMA NOVA)

У цю папку можна зберігати файли логотипу вашого сайту:

- `/public/logo/logo.svg` — Головний векторний логотип сайту
- `/public/logo/logo.png` — Альтернативний растровий логотип

### Як змінити логотип:
1. Замініть файл `logo.svg` або додайте свій файл `logo.png` у цю папку (`/public/logo/`).
2. Сайт автоматично використовує цей логотип у шапці (Header), футері (Footer), вікнах авторизації та сповіщеннях з ефектом м'якого сяйва (розсіювання).
