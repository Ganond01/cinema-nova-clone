# CinemaNOVA — копія для комісії

Очищена копія навчального проєкту онлайн-кінотеатру. Вона має окрему історію; основний приватний репозиторій не змінено.

Код: React, TypeScript, Vite, Express, Prisma/PostgreSQL, MinIO.

## Налаштування для локального ознайомлення
1. Скопіюйте `.env.example` у `.env` та задайте власні налаштування. Ключі API в копії відсутні.
2. Установіть залежності: `npm ci`.
3. За потреби налаштуйте `DATABASE_URL` і виконайте `npx prisma generate` та `npx prisma migrate deploy` для власної локальної бази.
4. Запуск розробки: `npm run dev`; збірка: `npm run build`.

Демонстраційні облікові записи використовують адреси `example.invalid` і значення `PUBLIC_DEMO_ONLY`. Автентифікація навчальна; не використовуйте реальні паролі чи персональні дані. Збирання та запуск цієї копії не перевірялися.

Конфігурації CI/CD наведено як неактивні приклади у `docs/ci-examples/`. Синхронізацію з робочими серверами вимкнено.

Докладний перелік очищення та межі перевірки: [SANITIZATION_REPORT.md](SANITIZATION_REPORT.md).
